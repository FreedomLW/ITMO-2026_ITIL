# Разработать собственный SLA-документ

## 1. Стороны и предмет соглашения

Поставщик - команда платформы AI-ассистента. 
Заказчик - Сервис "Импортозамещение IT"
Предмет - агентский режим ассистента в CLI и IDE-плагине.

## 2. Сущность услуги
### Границы
Сервис начинается с приёма запроса в клиенте и заканчивается показом ответа пользователя.
Зона: клиент -> backend (аутентификация, сборка контекста, оркестрация агента, вызов инструментов) -> передача в llm-proxy -> получение, обработка ответа и доставка в клиент.

**Входит:**
- Агентские сессии в CLI и в плагинах VS Code, JetBrains
- Harness агента (системные промпты, логика оркестрации, набор инструментов)
- Выполнение инструментов агента: чтение, изменение файлов, вызов MCP тулов и других тулов. 
- Поставка и обновление плагинов и клиентов, документация
- Защита данных в зоне поставщика: код и запросы пользователей
- Выбор самих моделей 

**Не входит:**
- inference и GPU-платформа (ответственность llm-proxy), 
- сеть, VPN, корпоративная аутентификация
- реализация MCP тулов с которыми работают агенты
- Прочие режимы ассистента: чат, ревью.

## 3. Цели соглашения
| Параметр                               | Ед.                              | Бизнес-потребность                                                                    |

| RTO / RPO                              | ч, мин                           | После аварии сервис возвращается за известное время, потеря истории сессий ограничена |
